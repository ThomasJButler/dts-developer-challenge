Design for the caseworker task-management tool

A single-user task tool built on GOV.UK Frontend. Server-rendered Nunjucks, progressive enhancement only, WCAG 2.2 AA.

Two artefacts to review:

Interactive prototype

A working, clickable version of all three screens, plus the delete confirmation, the empty state, the validation error state, and the success banner. Built with vanilla JavaScript over a fixed GOV.UK Frontend layout. Use the toolbar at the top to jump between states.

Open the prototype

Design spec

Annotated Nunjucks for every screen, rationale per choice, the full microcopy set in UK English, an accessibility checklist for the build team, and an explicit out-of-scope list. Each screen includes a live preview pulled from the prototype.

Read the spec

A short note on constraints

  • The prototype is JavaScript only because the design needs to be clickable here. The actual service is server-rendered Nunjucks consumed by an Express app, with no client-side router and no XHR. The spec shows the production markup.
  • The header is intentionally plain. This is an internal HMCTS tool, not a page on gov.uk, so it does not carry the GOV.UK crown or wordmark. The visual language, spacing, and components are GOV.UK Frontend.
  • All example data is fictional. Case references follow the pattern CR-2026-0142. No real names, no real emails, no real photos appear anywhere.
